# My First Repo

A tiny Python project made during **Lab 2** to practise git and GitHub.

## How to run

python greetings.py

## What's inside

- `greetings.py`: a few friendly functions
- `motto.txt`: our lab motto

## Author

Sharon Chen

## What I learned

- `git commit -m "..."`: save a snapshot of my work with a message
- `git checkout -b <name>`: create a new branch and switch to it
- `git merge <name>`: combine a branch into the current one
- `git push`: upload my commits to GitHub
- `git pull`: download new commits from GitHub
